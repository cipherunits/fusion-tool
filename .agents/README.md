# Fusion Tool agent skills

Skills teach Cursor agents how to maintain this CLI in sync with Fusion Framework.

| Skill | Use when |
|-------|----------|
| `fusion-cli` | Any CLI/generator work |
| `fusion-cli-init` | Changing `fusion init` |
| `fusion-cli-templates` | Editing embedded templates |
| `fusion-cli-parity` | Cross-language starter changes |
| `fusion-cli-testing` | Validation after generator changes |

Also read root `AGENTS.md`.
